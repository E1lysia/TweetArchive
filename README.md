# TweetArchive

Windows 本地 X / Twitter 推文归档与管理工具，基于 Python、PySide6 / Qt 和 gallery-dl。

## 功能

- 归档推文原文、图片、视频和纯文本内容。
- “正文待补全”页面可按原推 ID 补全旧记录，不依赖最新时间线；确认无正文的正常归档，无法读取的保留待补并记录原因，可暂停后重新运行。
- 区分原创、引用与转推，支持多选筛选。
- 按账号浏览、搜索、分组、修改显示名称或删除账号；删除保留本地资料，重新添加同一账号可恢复。
- 引用来源摘要旁提供可点击的原推链接。
- 按日期、关键词筛选，支持分页、网格与列表浏览。
- 网格/列表、内容类型及排序为统一浏览设置，切换账号和资料库页面时保持选择，重启后恢复；搜索、日期和阅读位置按账号及页面记忆。
- 中间内容下滑后显示返回顶部箭头；我的收藏位于全部推文下方。
- 全部推文网格采用自适应双列，短文字不占图片空位，图文带正文摘要，多图组合预览，引用来源以紧凑摘要呈现；窄区域自动变为单列。
- 收藏、标签、多图切换，以及保留媒体原始比例。
- 点击右侧媒体，在软件内放大查看图片、缩放拖动或播放视频，并保留系统打开入口。
- 暂停、继续下载队列，暂停后关闭软件；重启后手动继续，已保存内容保留。
- 配置 DeepL 或其他大模型翻译引擎。
- 翻译校验失败时最多重试两次，仍失败则跳过继续；任务日志与本地失败明细保留具体原因。
- 通过左下角小齿轮打开设置，左侧分别管理存储与归档、翻译模型及 X 登录。

## 下载与使用

面向普通用户的完整 Windows 软件包请从 [Releases](https://github.com/E1lysia/TweetArchive/releases/latest) 下载。当前版本为 **1.2.3**。

选择发布者上传的 `TweetArchive-1.2.3-win-x64.zip`，解压后阅读根目录的 `操作指南.html`，再启动 `TweetArchive.exe`。

GitHub 自动生成的 `Source code (zip)` 是源码，不包含完整运行环境。

每位使用者需要自行配置 X 登录和翻译服务。不要共享登录 cookies 或 API 密钥。

详细步骤见 [操作指南](docs/操作指南.md)。

## 开发说明

当前代码来自 Windows 本地开发环境，部分安装、预览与打包脚本仍使用 `D:\gallery-dl` 等本机路径。开发者需检查脚本中的路径并配置依赖；克隆源码后尚不能直接一键打包。

本地迭代默认只更新程序；收到明确的打包要求后再生成或替换分享 ZIP。

翻译校验失败时最多额外重试两次（配置的 `max_retries` 更低时按较低值执行），仍失败则跳过，其他条目继续处理。失败原因和推文标识写入任务日志，并保存至资料库的 `_推文归档/翻译记录/`。密钥、余额、接口或连接错误仍停止派发后续请求。重新补译只处理未保存译文的内容；重试可能产生额外 API 费用。

大模型翻译采用编号占位符与简单 JSON 返回格式，链接、用户名、话题及指定人名由程序在本机还原。保护编号遗漏、重复或变动时继续拒绝写入。DeepL 使用其原生 XML 翻译接口。

桌面依赖见 `desktop_app/requirements.txt`，启动器使用 .NET 8。桌面侧的历史开发说明见 `desktop_app/README.md`。

在配置好相应依赖的 Python 环境中运行测试：

```powershell
python -m unittest discover -s local_archive -p "test_*.py"
python -m unittest discover -s desktop_app -p "test_*.py"
```
