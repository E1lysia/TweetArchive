# TweetArchive 操作指南

适用版本：Windows x64 便携版 1.2.3。本文按最新整合版界面编写，已包含此前全部更新，无需叠加旧补丁。

## 1. 第一次使用：按这个顺序操作

1. 完整解压压缩包，双击“TweetArchive.exe”。
2. 点击左侧“归档账号”旁的人物加号图标，添加想归档的作者。
3. 双击解压目录的“刷新登录态.cmd”，按提示获取本人 Edge 中的 X 登录信息；也可在“齿轮设置 → X 登录”中导入已准备好的登录文件。
4. 如需中文翻译，点击左下角状态文字左侧的小齿轮 → “翻译模型”，选择引擎、填写本人 API 密钥，再试译固定样例。
5. 返回主界面，选中左侧账号，点击中栏“补充当前账号最新推文”。
6. 在顶部“任务队列”查看进度；任务结束后浏览图片、视频和推文。

首次打开是空资料库，需要自己添加账号。暂时不配置翻译也可以先下载、归档和阅读原文。

## 2. 解压与启动

将压缩包完整解压到自己有写入权限的目录，例如 `D:\TweetArchive`。确认目录里同时存在“TweetArchive.exe”、`python`、`资料库` 和 `tools` 等文件或文件夹。

双击“TweetArchive.exe”启动；若不能启动，再尝试“TweetArchive.cmd”。软件已包含 Python、Qt 和独立启动器，无需另外安装 Python 或 .NET。

请勿在压缩包内直接运行，也不要单独移动 EXE。程序和自己的归档都保存在解压目录，图片、视频较多时应选择空间充足的磁盘。

已有资料的用户请先暂停任务并退出软件，把新版完整解压到新目录。启动新版后，在“齿轮设置 → 存储与归档 → 打开已有资料库”选择原来的完整资料库。不要用分享包内的空 `tools/accounts.json` 覆盖原账号文件。X 登录文件及翻译密钥仍按新版程序目录单独配置或在本机迁移，原资料库保留。

本版面向 Windows 10 22H2 / Windows 11 的 x64 电脑；不适用于 macOS、手机或 Windows 32 位系统。

## 3. 添加想归档的作者

1. 在左侧找到“归档账号”，点击右侧的人物加号图标。
2. 输入 X 用户名，例如 `example_user` 或 `@example_user`。不要填写整条主页链接，也不要填写显示昵称。
3. 输入显示名称，可以留空；确认后，账号会出现在左侧列表。
4. 点击该账号，将后续浏览和“补充当前账号最新推文”的范围切换到这个作者。

点击“全部账号”右侧的小放大镜，弹出账号搜索框，可按姓名、用户名、目录名或分组名查找作者。回车或点击外部收起搜索框后仍保留筛选，放大镜高亮；清空搜索框可恢复全部账号。它只筛选左侧账号列表，不搜索推文；要搜索正文，请使用顶部搜索框。

“归档账号”指你想保存内容的作者；“X 登录账号”是你本人用来登录 X 的账号，二者可以不同。

### 账号分组、右键改名与删除

点击“归档账号”旁的文件夹加号图标可直接新建分组，也可以右键任意账号 → “新建分组”。右键账号 → “移到分组”选择已有分组，或“新建分组并移入”。一个账号归属一个分组，未分配的显示在“未分组”。

点击分组标题可以折叠或展开；搜索会临时展开符合条件的账号，支持按分组名查找，清空搜索后恢复折叠状态。右键分组标题可重命名或解散分组；解散后账号回到未分组，归档和收藏保留。

右键账号 → “重命名账号”可以修改添加时填写的显示名称，也可以继续多次修改。账号身份、X 用户名、媒体目录、已有推文、收藏及下载记录保持原关联。左侧名称、账号标题、搜索和归档账号标注会更新；推文原作者仍按来源显示。

右键账号 → “删除账号”可以将该账号从左侧列表和“全部推文”移除。删除前会确认，图片、视频、原文、译文、收藏和下载记录仍保留在本地；重新添加同一 X 用户名可恢复原目录和收藏，原分组仍存在时也会恢复分组。

请先暂停正在执行的任务，待显示“已暂停”后再删除。属于被删除账号的暂停任务会取消，其他账号的任务保留，并按账号身份重新确定执行范围。此入口不会删除磁盘文件。

分组、分组名称和折叠状态保存在资料库中，重启或复制迁移资料库后继续保留。更改文件保存位置请用左下角“齿轮设置 → 存储与归档”，入口已从中栏补充菜单移出。


设置入口为左下角翻译状态左侧的小齿轮。设置窗口左侧分别列出“存储与归档”“翻译模型”“X 登录”，可随时切换；“保存当前页”只保存当前页修改。关闭窗口会放弃尚未保存的修改。

## 4. 获取或导入本人 X 登录文件

补充需要有效的 X 登录信息。分享包现在提供“刷新登录态.cmd”，也支持导入 Netscape 格式的 `cookies.txt`。

### 方式一：使用随包的刷新工具（Edge）

1. 双击本解压目录中的“刷新登录态.cmd”。
2. 按提示先在 Edge 登录自己的 X 账号，保存网页内容，再自行完全退出 Edge（包括后台）。
3. 回到命令窗口按回车，工具会尝试打开 Edge 并加载随包的本地扩展，最多等待 4 分钟。
4. 如果没有自动完成，保持命令窗口打开，在已登录 X 的 Edge 个人资料中打开 `edge://extensions`，开启“开发人员模式”，点击“加载解压缩的扩展”，选择“TweetArchive.exe”旁边的 `TweetArchive-XLogin` 文件夹。若已经加载过，请在扩展卡片上点击“重新加载 / 刷新”。
5. 出现“成功”后，直接回到同目录的软件点击补充，无需再次导入。手动加载过本地扩展的，请在扩展页将它移除。

`TweetArchive-XLogin` 文件夹随分享包提供，里面有 manifest.json 和 background.js；超时后也会保留，无需到系统临时目录查找。单独加载随包扩展不会导出数据；应先运行刷新工具并按回车，再加载或重新加载扩展。

工具只将 X / Twitter 登录信息保存到当前解压目录，不强制关闭 Edge，不修改其他资料库。获取失败时保留已有文件。默认尝试使用 Edge 默认个人资料；多个个人资料时，请用已登录 X 的那个个人资料手动加载扩展。浏览器政策或版本可能限制自动加载，此时使用上面的手动步骤，或改用文件导入。

### 方式二：导入已有文件（其他浏览器也可）

1. 在自己的浏览器中登录 X，并确认能正常打开想归档的作者主页。
2. 使用你信任的 Cookie 导出工具，仅导出当前 X 站点的 Cookies，格式选择 Netscape / cookies.txt。
3. 打开软件左下角“齿轮设置 → X 登录”。
4. 点击“导入本人的 X 登录文件（cookies.txt）”，选择刚导出的文件。
5. 出现“登录文件已导入”后，即可返回主界面补充。

主程序不会自行读取浏览器；只有主动运行刷新工具并按回车后，才会尝试通过本地扩展获取本人登录信息。两种方式都不需要在软件里输入 X 密码。JSON、CSV 或普通文本文件不能只改名为 cookies.txt 来代替 Netscape 格式。

如果提示“文件中没有有效的 X 登录信息”，请确认导出的是已登录的 X 站点，而非其他网站；如果文件已过期，请重新导出。软件只保存导入文件中属于 x.com / twitter.com 的有效 Cookies。

登录文件相当于登录凭证，请留在自己的电脑上，不要连同归档目录一起公开分享。

## 5. 补充图片、视频和原文

1. 在左侧选择一个已添加的账号。
2. 点击中栏顶部“补充当前账号最新推文”。如果控件已随中栏滚走，可点击中栏右下角出现的向上箭头直达顶部。
3. 点击顶部“任务队列”，查看当前步骤与日志。
4. 等待图片、视频下载和原文归档完成；启用自动补译时，还会继续处理待译正文。
5. 完成后软件会重新读取资料库，并显示本次新增情况。提示条右侧的小 × 可关闭提示，不影响任务或日志。

选择左侧“全部账号”后，中栏按钮显示“补充全部最新推文”。补充按钮右侧的小箭头也可以选择当前账号或全部账号。

“补充最新推文”使用上一次成功完成的时间检查点，首次从本地最新账号事件确定边界，并重叠回扫三天。接口按最新到较旧读取，到达边界并连续遇到一批旧记录后停止；500 条是每批处理量，超过后自动继续，不是单次总上限。正文、图片、视频共用时间线结果，媒体按账号目录归档。没有本地记录的首次导入会分批读取接口可访问的时间线，可随时暂停。

转推按转推事件时间计算，引用来源的早期发布时间不会误作停止边界。下载或索引失败时不推进完成检查点，重试会保留未完成时间区间。三天回扫之前的旧缺口、旧帖修改或恢复可见，以及 X 未返回、已删除或无访问权限的内容，仍可能无法取得；较早缺口请另用“补历史正文”。

### 归档范围与历史正文

在“齿轮设置 → 存储与归档”中设置账号补充范围：纯文字默认开启，回复默认关闭，可勾选原创、引用、转推与关联来源。这里的抓取范围与页面多选筛选独立。

补充按钮右侧菜单 → “补历史正文”：选择最早日期（可留空）、单次扫描上限和是否从未完成位置继续，再点击“开始归档”。范围采用当前账号（或全部账号）及归档设置，不受页面搜索、月份影响。历史正文不会下载媒体，只有勾选补译选项才会在本次完成后自动翻译。

历史补录也可以通过右上角“暂停”或任务队列中的“暂停任务”暂停。已保存的正文保留；点击“继续”或重新启动后继续，可从保存的历史游标重新检查，可能重放上一页但不会重复建记录。若接口未提供游标，日志会提示下次增大扫描上限。起始日期限制保存范围，不保证接口能返回所有历史记录。

右上角“暂停”以及任务队列中的“暂停任务”会停止当前任务及其下载子进程，并暂停后续排队任务。已保存的正文、译文和下载文件保留，任务显示“已暂停”。再次点击“继续”会重新检查并跳过已完成下载；未完成的文件能否续传取决于下载器和服务端，可能需要重下。

暂停后可以直接关闭软件；任务运行中点击主窗口关闭，会询问是否暂停任务并退出，确认后等待进程停止再关闭。重新打开软件时，未完成任务保持暂停，不会自动联网，点击右上角“继续”恢复原队列。只关闭“任务队列”小窗口不会停止下载。

部分步骤失败时，已经下载或保存的内容会保留；在任务队列查看原因、修复后再次补充。资料库复制迁移期间仍需等迁移完成后退出。

## 6. 配置翻译引擎

打开“齿轮设置 → 翻译模型”，在“翻译引擎”中选择服务。

| 引擎 | 需要填写什么 | 使用说明 |
| --- | --- | --- |
| DeepL | 本人的 DeepL API 密钥 | 使用官方翻译接口；已有配置可以继续使用 |
| DeepSeek | API 密钥、模型名称、接口地址 | 默认提供对应预设，可按服务商账户权限修改模型 |
| 通义千问 | 百炼 API 密钥、模型名称、接口地址 | 预设为北京地域；地址和密钥必须对应正确地域 |
| Kimi | 开放平台 API 密钥、模型名称、接口地址 | 请使用开放平台的模型与密钥 |
| 自定义兼容接口 | 兼容服务的地址、模型名称及所需密钥 | 支持 Chat Completions 兼容服务，不等于支持所有厂商原生接口 |

1. 选择引擎；可点击“打开所选服务平台”进入对应平台。
2. 在本机输入对应服务的 API 密钥。大模型服务还需确认模型名称与接口地址。
3. 初次使用可将“并发请求数”设为 1～3，“请求超时”设为 60 秒；经常超时可适当调高。
4. 设置“单次原文字符上限”，例如 10000，控制一次任务处理的原文长度。
5. 点击“保存并试译固定样例”。软件会保存设置，并在任务队列显示固定日文样例的译文和耗时。
6. 样例成功后，返回主界面点击“补译中文”。

各服务分别保存密钥，切换引擎不会串用其他服务的密钥。输入框不会回显已经保存的密钥；留空表示保留，不表示当前没有配置。

API 密钥是服务商开放平台发放的凭证，不是网页登录密码。具体可用模型、额度和计费规则以所选服务商账户为准。大模型通常按输入、输出 token 计费；原文字符上限不能当作金额上限。

### 翻译范围与已有译文

- “补译中文”按当前选择的归档账号与多选“内容类型”的合集处理待译正文，不仅限于当前页，也不以当前搜索或年月筛选作为补译边界。
- 关闭自动补译选项后，补充不再自动翻译；仍可手动点击“补译中文”。
- 已有译文默认保留，不会因切换引擎而自动重译。相同原文可以复用本地缓存。
- 达到字符上限后，剩余内容仍是待翻译状态，可以再次运行补译。
- 翻译处理推文文字正文，不包含图片内文字识别或视频字幕翻译。

### 个别译文校验失败时

大模型翻译会将链接、@用户名、话题和指定人名替换成编号，由程序在本机还原；模型只需返回简单 JSON，不需要生成 XML。DeepL 继续使用其原生 XML 翻译接口。

格式或保护编号校验失败时，单条最多额外重试两次（重试配置更低时按较低值执行）；仍失败则跳过，继续处理其余内容。重试可能产生额外 API 费用。编号遗漏、变动或重复的译文不会写入。

任务显示“部分完成”时，已保存译文仍保留，失败项继续待译。任务日志列出对应推文和具体原因，资料库的 `_推文归档/翻译记录/` 中保存当次失败明细；历史明细不会因后续重试成功而自动改写。可再次点击“补译中文”或任务队列的“重试翻译”，也可切换模型再重试，已有译文会跳过。

密钥无效、余额不足、接口或网络错误仍会停止派发后续请求，应先按日志处理后再继续。字符上限限制的是本次选择的原文总量；自动重试不等于费用上限。

### 按原推 ID 补全旧推文

在左侧选择“正文待补全”，点击中栏“补全推文”。选择单个账号时处理该账号全部待补记录，选择“全部账号”时处理所有已添加账号；不受当前搜索、日期和内容类型筛选影响，也不受最新推文时间限制。

此任务只读取正文，不重新下载媒体、不自动调用翻译服务。取得正文后自动归档并核对内容类型；已确认没有文字的推文正常归档，不再显示待补。需要中文时再使用“补译中文”。

任务队列可以暂停；再次运行只处理仍待补全记录。原推已删除、账号无读取权限、登录过期或接口限流时可能无法补齐，记录保留待补，具体提示见任务日志及右侧详情。限流表示读取请求受到临时限制，不代表翻译服务余额不足；请避免连续重复点击，稍后重试。当前版本会将登录与限流归入同一停止提示，不能仅凭该提示确认具体原因。

## 7. 浏览、搜索与筛选

| 区域或按钮 | 用法 |
| --- | --- |
| 全部推文 | 浏览已归档的纯文字、图片与视频推文 |
| 图片图库 / 视频库 / 纯文字 | 按媒体形式筛选；纯文字只包含来源确实无媒体的记录 |
| 我的收藏 | 查看自己收藏的推文 |
| 待翻译 | 查找有正文但尚无中文译文的记录 |
| 正文待补全 | 查找已有本地媒体、原文尚待核对的记录 |
| 顶部搜索框 | 搜索原文、译文、作者、推文 ID 或自定义标签 |
| 全部时间 | 按年、月筛选本地已有内容；切换时间不会自动下载历史推文 |
| 新 → 旧 / 旧 → 新 | 改变当前筛选结果的排序 |
| 网格 / 列表 | 切换卡片展示方式 |

“我的收藏”位于“全部推文”下方。收藏后，右侧收藏按钮和中栏卡片均显示黄色实心星；再次点击可以取消。顶部搜索框在窗口中水平居中。

点击中栏卡片，右侧显示该条推文的作者、媒体和正文。补充、补译、网格、列表等控件随中栏一起滚动；顶部搜索、侧栏和右侧详情独立保留。可拖动栏间分隔线调整宽度。

“全部推文”的网格采用自适应双列：短文字卡片随内容收紧，图文先显示摘要，最多四张图片组合预览，引用来源以紧凑摘要呈现；中栏较窄时自动变为单列。图片保持原比例，选中卡片使用薄荷色边框。其余资料库页面及列表样式沿用现有布局。

网格/列表、内容类型和排序为统一浏览设置，切换账号或资料库页面后保持当前选择，重启后也会恢复。搜索、日期、页码和阅读位置仍按账号及页面分别记忆。更改内容类型或排序后，原来的页码和滚动位置可能不再适用，此时从该账号的结果首页显示；只更改网格/列表时保留原页并定位所选推文。

向下滚动中栏后，右下角会出现向上箭头。点击返回当前页顶部，不改变账号、页码、选中推文或右侧阅读位置。

### 原创、引用、转推如何区分

| 内容类型 | 含义 |
| --- | --- |
| 原创 | 作者本人发布的内容 |
| 引用 | 作者带评论引用其他推文 |
| 转推 | 作者转发他人的推文，详情保留原作者和归档账号 |
| 关联来源 | 关联媒体的来源内容，保留原作者；不在缺少证据时当作本账号原创或转推 |

“原创 / 引用 / 转推 / 关联来源”可同时选中，按“或”合并结果，例如原创与引用一起显示。“全部”一键全选，至少保留一种类型；当前组合在切换账号后保持。卡片文字标签和勾选状态辅助识别。

## 8. 看多张图片与播放视频

点击右侧图片即可在软件内打开大图窗口：保持原始比例，滚轮缩放、按住鼠标拖动；可点击“适应窗口”或“100%”。左右箭头切换同条推文的媒体，F11 全屏，Esc 关闭。

图片全屏时，鼠标在画面中静止两秒，上下工具栏自动隐藏；移动鼠标后恢复。悬停工具栏操作时保持显示，退出全屏后工具栏始终显示。

同一条推文有多张图片时，将鼠标放在右侧图片预览上：向下滚轮看下一张，向上看上一张。到首张或末张会停止，不会继续切进视频。

预览下方的媒体选择框以及左右箭头可以切换同一条推文中的图片、视频；只有一项时箭头会禁用。

点击右侧视频画面即可在软件内放大并自动播放，可暂停、拖动进度条及调节音量；关闭大图窗口会停止该窗口的播放。也可使用右侧原有的“播放”按钮。媒体保持原始宽高比，竖图两侧或宽图上下出现留空属于正常显示。

确认原推没有文字正文时，记录正常归档并显示“已确认原推无文字正文，无需翻译”；尚未取得正文的记录保留“待核对”，不能因此认定为空白推文或原创。

软件按账号目录检查媒体文件是否实际存在，旧的下载记录本身不代表文件仍在。升级时若旧 downloads 目录有可匹配的媒体，补充任务会核对并复制回对应账号目录，源文件保留。

纯文字卡片直接显示正文摘要，没有空白媒体占位；点开后右侧隐藏媒体预览及选择控件，阅读全文。有媒体但本地文件缺失时仍保留正文，并显示媒体待下载/缺失，不能当作纯文字。引用来源已归档时会显示来源摘要；点击摘要上方“查看来源推文 ↗”可在浏览器打开被引用的原推。即使尚未保存来源正文，只要已有来源编号，也会显示链接。缺少来源信息时显示“来源链接暂缺”，重新补充可尝试补齐。

在右侧点击“双语 / 中文 / 原文”切换阅读语言。如果内置播放器无法播放，可点击大图窗口的“系统打开”，或使用“更多 → 打开媒体 / 系统播放器”。

## 9. 跳页、查找旧内容与保存阅读位置

底部分页固定显示。可用首页、上一页、页码、下一页、末页，或在“跳到”中输入页数，按回车或点“跳转”。窄栏时跳页输入会换到第二行，当前页数显示在右侧。

想直接看旧内容，可以先切换“旧 → 新”，也可以在“全部时间”面板按年月查找。面板底部还有“定位到最新一条 / 定位到最早一条”。定位会清除年月范围，并保留账号、媒体分类、搜索、内容类型和排序条件。

软件会记住分类、账号、搜索、日期、页码、选中的推文与滚动位置；关闭重开或任务结束刷新后会尝试恢复。不同分类和账号分别记录浏览进度，网格/列表、内容类型及排序则统一记忆。旧版浏览偏好首次升级时沿用最后打开账号的这三项选择。

## 10. 收藏、标签与打开原文件

1. 选中推文，在右侧作者旁点击“☆ 收藏”；再次点击可取消收藏。
2. 点击“更多 → 编辑标签”，用空格分隔多个标签，例如“演出 海报”，确认后保存。
3. 在顶部搜索标签，或切换左侧“我的收藏”，快速找回内容。

“更多”还提供打开原推、打开来源推文、打开所在文件夹以及打开媒体等操作。没有关联来源的记录不会显示来源入口。打开原推需要网络；已下载媒体和已保存正文可以离线阅读。

## 11. 备份、迁移与再次分享

打开“齿轮设置 → 存储与归档”，可以复制现有资料并切换位置、新建空资料库用于教学，或者打开已有的完整资料库。新位置请选择空目录；不能是当前资料库的上级或下级目录。

迁移期间不能执行下载/翻译任务。软件复制媒体、正文、译文、账号、收藏、标签和增量下载清单，校验后切换，原目录保留；失败时未完成目录不能作为完整资料库打开。登录文件、API 密钥和程序留在程序目录。磁盘未连接时会要求选择完整资料库，不会自动建立空库冒充原数据。

备份前先退出软件。默认位置可复制整个解压目录；更改位置后，程序目录和外部资料库目录都需要备份。迁移到新电脑后，启动时按提示选择完整资料库；不要只移动数据库或 EXE。

| 位置 | 保存内容 |
| --- | --- |
| 各作者目录 | 下载的图片、视频及导出的推文文件 |
| _推文归档/tweets.sqlite | 推文原文、中文译文、媒体路径和类型信息 |
| _推文归档/manager.sqlite | 收藏、标签、浏览偏好、任务记录和暂停队列 |
| tools/accounts.json | 自己添加的归档账号 |
| cookies.txt | 自己导入的 X 登录信息 |
| tools/deepl.local.json / tools/translation.local.json | 翻译服务配置与密钥 |

分享给新用户时，请发送原始的干净 ZIP 和这份指南。使用后的程序目录会包含自己的登录信息、密钥和私人归档，不适合直接再次打包发给别人。

## 12. 常见问题

### 第一次打开没有任何内容

分享版为空资料库，这是正常情况。按第 3～5 节添加作者、导入本人登录文件，再补充。

### 提示登录文件无效、登录失效或 AuthRequired

先在浏览器确认本人 X 账号仍能正常访问，再运行本解压目录的“刷新登录态.cmd”；也可以重新导出当前站点的 Netscape 格式 Cookies，在软件设置中重新导入，然后重试补充。登录状态也不能绕过作者的访问权限。

### 文件夹有新文件，但界面没看到

先确认任务队列中的下载、归档步骤是否结束。再切回“全部推文”和正确账号，清空搜索，选择“全部时间”和内容类型“全部”。如仍未显示，在设置中点击“刷新资料库与视频封面”，并查看“正文待补全”与任务日志。

### 翻译一直显示待翻译

检查引擎是否有对应密钥、服务商额度是否足够、模型与地址是否正确。先试译固定样例；若只是达到本次字符上限，再点一次“补译中文”。超时或限流时可降低并发，适当增加超时时间后重试。

若日志提示保护编号、格式或译文校验失败，原文未被修改；失败项仍保留待译，其余有效译文已保存。查看任务日志的失败汇总，重试或切换模型继续，不需要删除已保存内容。

### 切换了大模型，旧译文没有变化

已有译文默认保留，切换引擎只影响后续待译内容；相同原文还可能复用缓存。这不是切换失败。

### API 返回 401、403、404 或 429

401 通常先检查密钥；403 检查服务权限；404 检查地址和模型名称；429 检查限流或额度。具体原因以任务日志和服务商控制台为准，不要把包含密钥的配置文件发给他人排查。

### 程序打不开或视频无法播放

确认已完整解压、目录可写、系统为 Windows x64；尝试备用“TweetArchive.cmd”。若存在“资料库/启动错误.log”，可用它定位启动问题。视频可尝试交给系统播放器打开。

### 下载或翻译任务没有立刻结束

在顶部任务队列查看当前步骤和日志。图片、视频较多或服务商响应较慢时可以继续等待，也可以点击“暂停”，待显示“已暂停”后关闭软件，之后点击“继续”恢复。任务未完成时不要反复点击补充，以免排入重复任务。
