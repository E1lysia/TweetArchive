- 补全任务不重新下载媒体、不自动调用翻译；需要中文时再使用“补译中文”。

本包包含 Python、Qt 及独立启动器，无需额外安装 Python 或 .NET。首次使用需要自行添加归档账号，配置本人 X 登录信息；翻译服务需自行配置。
