# 推文资料库

双击 `解压目录中的“推文资料库.exe”` 或 `启动资料库.cmd` 启动。默认继续使用原账号目录；只有在“存储与归档”中主动复制迁移或切换时才更改资料库位置。

- 界面布局：固定使用最新版阅读布局，加宽详情、增大正文字号，将收藏和阅读语言放在上方；打开原推、来源、媒体、文件夹及编辑标签收进“更多 ···”。自动记住栏宽与浏览位置，右上角不再显示布局切换。
- 中栏联动：补新、补译中文、网格、列表随中栏推文一起滚动，拖动分栏时一起调整位置。顶部搜索和右侧详情独立保留，底部分页固定。卡片随栏宽自动调整列数，列表模式同样使用统一卡片样式。
- 操作入口：补新按钮集中在中栏，已选账号时补新当前账号，全部账号时补新所有账号；按钮右侧小箭头可选择范围。任务队列移到顶部，添加账号入口是左侧“归档账号”旁的“＋”。

- 全部推文：显示已归档的纯文字、图片与视频推文，包括原创、引用及转推；卡片和详情均有类型标记。
- 内容类型：点击“原创 / 引用 / 转推 / 关联来源”多选筛选，按“或”组合；“全部”一键全选。引用表示本人带评论引用其他推文；转推保留原作者，同时标明归档账号。关联来源保留原作者，不会冒充本账号原创，也不会在缺少转推事件证据时标成转推。
- 图片图库 / 视频资料库：按媒体类型浏览。选中视频后，右侧点击播放；支持暂停、拖动进度。播放不兼容的格式可用“打开媒体 / 系统播放器”。
- 右侧阅读：作者下方点击“双语 / 中文 / 原文”；预览下方通过媒体下拉框或左右箭头切换同一推文里的图片和视频。首项与末项对应箭头自动禁用。
- 滚轮切图：鼠标停在右侧图片预览上，向下滚看下一张，向上滚看上一张；到第一张或最后一张停止，不会滚进视频。
- 账号搜索：左侧“归档账号”下可按姓名、用户名或账号目录名搜索，支持大小写混输。搜索只筛选账号列表，不改变当前资料库内容；账号较多时可独立滚动。
- 展示比例：图片和视频封面完整等比例显示，竖屏两侧留深色背景，宽屏上下留空；右侧播放也保持原比例。
- 搜索：搜索原文、中文、作者、推文 ID 或自定义标签；可切换网格/列表。
- 按年月浏览：点击“全部时间”选择年份或月份，面板显示当前账号、媒体分类和搜索结果的数量；无内容的月份置灰。可查看整年，也可随时返回全部时间。
- 时间定位：打开“全部时间”面板，底部可“定位到最新一条 / 定位到最早一条”。定位会清除年月范围，保留账号、媒体分类、内容类型、搜索和排序，只跳到目标记录所在页并选中它。
- 自由跳页：可点击首页、末页或页码，也可输入页数后按回车或点“跳转”。
- 排序与显示方式：“排序：新 → 旧 / 旧 → 新”仅调整当前筛选结果的排列顺序，不清除年月或搜索条件；“网格 / 列表”调整显示方式，浅绿色表示当前选择。其余下拉选项采用深色底、亮色文字。
- 分页布局：首页、上一页、页码、下一页、末页和跳页输入集中在底部左侧，当前页数显示在最右侧。窄栏下跳页输入自动换到第二行，所有功能保留。
- 浏览位置：自动记住当前分类、账号、时间筛选、排序、搜索、页码、选中的推文与滚动位置，关闭重开或任务完成刷新时恢复。各分类和账号分别记录浏览进度。
- 收藏与标签：保存在 `_推文归档/manager.sqlite`；在“更多 → 编辑标签”中填写并确定后保存。
- 补新：先同步账号正文（含已启用的纯文字），再下载图片与视频、整理目录及关联媒体，按设置自动补译。任务队列显示过程和错误。运行时请保持软件开启。
- 补新结果：完成后自动重新读取归档，按类型显示新增数量和正文待补全数量。后续补新会从包含转推的时间线抓取媒体；首次启用后可能纳入以前未下载的转推。可点“查看最新”清除时间、搜索和类型筛选，跳到最新内容。
- 补译中文：使用当前选择的翻译引擎，跳过已有译文；已选择内容类型时，补译所选类型的合集。达到单次字符上限的记录保留待翻译状态，可再次补译，现有译文不会覆盖。
- 翻译引擎：打开“设置与翻译”，可选 DeepL、DeepSeek、通义千问、Kimi 或自定义兼容接口。填写对应服务的 API 密钥；大模型还可修改模型名称和接口地址。各服务分别记住密钥，切换服务时不会串用密钥，输入框不回显已保存的值。原 DeepL 密钥继续保存在原配置文件。
- 测试引擎：点击“保存并试译固定样例”，保存当前选择后向所选服务发送一条固定日文测试句，在任务队列查看译文与耗时；测试不会读取、修改归档推文。API 按服务商规则计费，没有所选服务的密钥时不能验证云端连接。
- 补译规则：切换引擎只影响待译内容，已有译文不覆盖，相同原文优先复用本地缓存。新译文记录引擎、模型、原文校验值和时间；模型若截断输出或改变受保护的链接、标签、用户名，该条仍保留待翻译。可以在任务日志查看失败原因后重试。
- 用量设置：字符上限限制每次任务所处理的原文长度；大模型实际费用通常按输入和输出 token 计算，不能将该上限当作金额上限。并发请求数建议先选 1～3。关闭“补新完成后自动补译”后仍可手动点击“补译中文”。
- 正文待补全：尚未取得原文的本地媒体，补新会重试；在核对前不标成原创或转推。
- 添加账号：输入 X 用户名，使用“补新当前账号”开始下载。

DeepL 密钥保存在本机 `tools/deepl.local.json`，其他服务的配置和密钥保存在本机 `tools/translation.local.json`，设置界面不会回显已保存的密钥。账号登录失效时，在“设置与翻译”中重新导入本人 X 登录文件。

迁移前的数据库与脚本备份在 `_推文归档/backups/desktop-*`。软件界面依赖放在 `资料库/vendor`，不要单独移动程序文件。


## 1.1.0 新增操作

- 内容类型可多选，原创与引用同时勾选时显示两类合集；“全部”为一键全选。页面类型不会改变抓取范围。
- 手动补译采用当前账号和全部选中的内容类型，不局限当前页、搜索或月份；已有译文保留。
- 设置与翻译 → 存储与归档：选择数据位置，可复制现有资料并切换、新建空资料库、打开已有资料库；任务执行期间不能切换。原位置保留。
- 登录文件、API 密钥与程序保存在程序目录；图片、视频、正文、译文、账号、收藏、标签和下载清单属于资料库。
- 纯文字：补新会先同步正文再下载媒体。左侧“纯文字”查看来源确实没有媒体的推文；有媒体但没下载成功的内容保留为媒体待下载/缺失。
- 补新菜单 → 补历史正文：设最早日期、单次扫描上限并选择是否继续，可在任务队列停止当前历史补录。接口未提供游标时，下次需要增大扫描上限。
- 归档范围在存储与归档中设置，纯文字默认开启、回复默认关闭；选择原创、引用、转推及关联来源。历史正文不自动触发翻译，需勾选或随后手动补译。
- 媒体文件不存在时正文仍保留。纯文字卡片直接展示正文，右侧隐藏媒体控件；支持离线搜索、翻译、收藏、标签与导出。
